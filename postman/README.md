# Postman — BloxFi API

**Collection:** `api_bloxfi.postman_collection.json`

Use this collection for E2E testing. This README is the flow guide; see **TEST_SCRIPTS_REFERENCE.md** for script details. See **RAMP_E2E_POSTMAN_FLOW.md** for on-ramp / off-ramp webhook sequences.

## Setup

1. **Import** the collection in Postman (File → Import → select `api_bloxfi.postman_collection.json`).
2. **Set collection variables:**
   - `baseUrl` — e.g. `http://localhost:3000` (default).
   - `apiKey` — Bearer token (shared secret). Must match server env `API_KEY`.
   - `userId` — Pre-filled or set by **Create Business User**.
   - `requestId` — Auto-generated by Pre-request Scripts on idempotent POSTs.
   - `payoutCorridorAsset`, `payoutCorridorCountry`, `payoutDestinationType`, `payoutBeneficiaryType` — Auto-set by **List payout corridors (USD / GE)** test script (defaults: USD, GE, wire, business).
   - `webhookSecret` — For **Webhooks** (= server `WEBHOOK_SECRET`).
   - `palremitProvisionedAccountId` — From DB after Create Onramp/Offramp.
   - `onrampFiatAssetCode` / `offrampCryptoAssetCode` / `offrampCryptoNetwork` — Match ramp bodies.

3. **Auto-saved variables** (test scripts):
   - `userId`, `fileId`, `accountId`, `walletId`, `onrampId`, `onrampTxnRef`, `offrampId`, `offrampTxnRef`
   - `payoutCorridor*` — from list corridors

## Offramp payout account

1. **List payout corridors** — `GET /api/v1/payout-corridors?asset=…&country=…`
2. **Get corridor requirements** — four query params; build form from `destinationFields`.
3. **Create Account (offramp)** — `corridor` + snake_case `destination` → stored as **`providerPayout`**. Corridor list/detail may include **`payoutRailLabel`** (display name, e.g. Fedwire).
4. **Create Offramp** — `destination.accountId` = `{{accountId}}`; omit `destination.amount` (server-computed net fiat after **`transferFee`**).

For **NGN**, use **Create Account (offramp, NGN)** after **Get corridor requirements (NGN local_bank)**.

## E2E testing flow

1. **Readiness** → **Health check**
2. **Create Business User** → KYB flow → approved for target fiat rail
3. **Payout corridors** → **Create Account (offramp)**
4. **Add External Wallet** + **List networks** for chain code
5. **Get ramp rates** (optional fee preview) → **Create Offramp** → webhooks → **Get Offramp** / **Retry Fiat Payout**

**Apply DB migration** (once per environment):

```bash
npx prisma migrate deploy
```

## Auth

Bearer `{{apiKey}}` at collection level. **Health**, **Readiness**, and **Webhooks** use No Auth (webhooks use HMAC).

## Palremit corridor API mapping

| BloxFi | Palremit |
|--------|----------|
| `GET /api/v1/payout-corridors` | `GET /v1/withdrawals/corridors` (filter) |
| `GET /api/v1/payout-corridors/requirements` | Same path, four fiat keys → detail |
| Offramp fiat withdrawal | `POST /v1/withdrawals` with `local_bank` / `wire`, `country`, no `payout_rail` |
